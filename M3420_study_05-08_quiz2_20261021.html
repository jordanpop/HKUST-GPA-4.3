第 5 課 · 原 PDF 52 頁

From Exposure to Comprehension

按原講義次序整理 · 頁碼指 PDF 頁序

一個廣告出現喺眼前，唔代表消費者留意到，更唔代表佢理解咗。呢課沿住 Exposure → Attention → Interpretation，解釋外界刺激點樣經感官接收、被選擇，再靠已有知識變成有意思嘅訊息。重點係分清每一步，以及品牌可以喺邊一步改善溝通。

PDF 第 3–11 頁

1. 接觸刺激同感官反應

整體資訊處理模型由刺激（Stimuli）開始，經選擇（Selection）、解讀／感知（Interpretation / Perception）、信念（Beliefs）、態度（Attitudes），再到選擇／行為（Choice / Behavior）。個人特質、環境文化，以及 Memory and Knowledge 都會影響過程。Perception 係選擇、組織同解讀刺激，形成有意義整體圖像嘅過程。

接觸刺激叫 Exposure；感官直接而即時嘅反應叫 Sensation。視、聽、嗅、味、觸分別由眼、耳、鼻、口、皮膚接收。媒體選擇要配合目標受眾，包括廣播、印刷、植入、網絡同贊助。

講義圖像例子：LUSH 用感官體驗；Apple 店讓人睇、摸、聽，建立生活方式形象；Singapore Airlines 將 Floridian Waters 香味連結機艙體驗；Westin 用白茶、雪松同雲呢拿作氣味識別。

圖中顏色講義列出嘅聯想／用途
Yellow樂觀、年輕；吸引櫥窗購物者
Red能量、急切；清貨促銷
Blue信任、安全；銀行及企業
Green財富、放鬆
Orange行動提示，例如購買或訂閱
Pink浪漫、女性化定位
Black力量、俐落；奢侈品
Purple舒緩；美容產品

第 9 頁將紅橙、黑、royal blue 配對 impulse shoppers；navy blue、teal 配對 budget shoppers；粉紅、sky blue、rose 配對 traditional buyers。呢啲係講義引用嘅美國市場圖例，唔好寫成所有文化都必然相同。

Exam trap：Exposure 只表示有接觸；Sensation、Attention 同 Interpretation 並唔係同一回事。

2. 察覺門檻、差異同選擇性接觸

最低幾大刺激先察覺「有嘢」，叫 Absolute threshold。廣告首先要跨過呢個門檻先有機會被注意。聽覺例子係安靜環境下最微弱而可察覺嘅鐘聲；講義指出年齡會影響察覺極低或極高聲音嘅能力。刺激長期不變，亦會逐漸習慣。

兩個相似刺激之間最細可察覺差異，叫 Differential threshold / Just Noticeable Difference (JND)。Weber’s Law 強調相對比例：原本刺激越大，要增加越多先覺得有分別。唔係任何產品加同一金額都一樣明顯。講義例子由 HK$24 到 HK$25，同 HK$7,488 到 HK$7,988，要比較相對改幅。品牌想改善被見到，就要高於相關 JND；想負面改動唔易察覺，會控制喺門檻以下。

弱到或短到未能有意識察覺嘅刺激屬 Subliminal perception。講義指出研究未證明 subliminal advertising 能造成行為改變，但部分研究見到 affective reactions 可能受影響。Tostitos 標誌藏住兩人蘸 salsa；Citroën 廣告用粗體串起暗示訊息。呢啲圖例唔構成「能操控購買」嘅證明。

曝光亦受廣告位置同分銷影響：電視廣告時段開頭／中間、雜誌封面／內封、貨架位置、end-of-aisle、POP display 都改變接觸機會。講義區分雜誌四個封面位置，指出封底通常最昂貴，其次兩個內封。

概念判斷線索
Selective exposure主動尋找愉快、認同自己或支持既有購買嘅訊息
Selective attention需求相關時特別留意某種訊息
Perceptual defense屏蔽有威脅嘅刺激
Perceptual blocking因資訊轟炸而調走注意力
Zipping / Zapping快轉錄影廣告 / 轉台避廣告

Exam trap：Absolute threshold 比「有／冇」；JND 比「變咗幾多」。隱藏圖案唔等於已證實有效嘅 subliminal persuasion。

3. 注意力有限，熟悉亦可能令你忽略

將心智活動投放喺刺激上叫 Attention。注意力有選擇性、容量有限，而且可以分配畀幾個刺激。陌生商店要花資源搵路，因此可能更難留意新產品。

熟悉到逐漸唔再留意，係 Adaptation / habituation。稻草人圖例由最初嚇走雀，到後來雀停返上面，展示重複刺激嘅注意力下降。

Pre-attentive processing 係未有意識聚焦時，對周邊視野訊息作處理。例如一堆藍圓形中嘅紅點可憑色相突出。講義用 Hemispheric lateralization 解釋視野位置：左視野訊息主要送到右半球，右視野送到左半球；因此圖像放左視野、文字放右視野較利於非焦點處理。前提係刺激真係位於周邊視野，唔係觀眾正望住佢。

講義嘅溝通對照重點
Left-brain marketing邏輯、實用性、產品用法、功能及用家證言
Right-brain marketing體驗、情緒、故事、驚喜及幽默

Kellogg’s 圖例對比母子體驗同營養資料；KitKat bench 係體驗型例子。部分研究指出先前嘅非焦點接觸可以影響品牌好感及選擇。講義亦提到性別 lateralization 說法受到研究挑戰，唔應推成固定人格分類。

Exam trap：非焦點處理唔等於完全冇接收資訊；左右視野原則亦唔等於「每個人只用左腦或右腦」。

4. 點樣令刺激被注意

刺激本身嘅對比、大小、顏色、位置同新奇程度，會影響佢能否穿過資訊雜訊。Wish-Bone 用蔬菜直接呈現產品內容，將抽象賣點變成容易理解嘅具體圖像。

做法點樣用
Isolation空白環境只放少量刺激，減少競爭
Size / intensity加大畫面或貨架面積；較亮顏色、較大聲音
Location店內眼睛水平、通道尾；講義亦提雜誌前部及左上角
Surprise / novelty違反預期，例子係非典型尺寸或擺設
Distinctiveness包裝、顏色、設計同競爭者拉開距離
Human attraction名人吸引目光
Entertainment有趣或逗笑嘅內容
Learned attention-inducing stimuli例如門鐘聲或已學識要留意嘅字眼
Less clutter揀較少刺激互相競爭嘅媒體或環境

Exam trap：吸引到眼球只完成 Attention，唔保證理解、記得品牌或購買。

PDF 第 40–49 頁

5. 用既有框架解讀，再組成整體

賦予感官刺激意思叫 Interpretation。已有認知框架 Schema 幫我哋快速組織資訊；圖例包括 person schemas、social schemas、self-schemas 同 event schemas。

Organization 係將刺激分組，當整體理解。Gestalt 重點係整體意義大過零散部分相加。

原則意思及例子
Figure and ground主體係注意焦點／positive space，背景係周圍／negative space。FedEx 箭嘴同人面／花瓶圖展示主體背景切換。
Product placementForeground 將產品變成場景焦點；background 將品牌融入環境，較自然地建立聯想。Pepsi、電影手錶、Home Alone 係講義例子。
Grouping / proximity靠近嘅物件較易視為一組；亦可用色調、顏色、形狀、大小連起整體印象，有助記憶。
Closure人會補完缺少部分，例如 WWF 熊貓圖。講義指出未完成訊息可能更易記住。

Exam trap：Figure 並唔一定等於最大件物件，而係被感知為主體嘅部分；Grouping 同 Closure 分別係「組合」同「補完」。

6. 解讀點樣出現偏差

消費者會將既有意思套落新刺激。Stereotypes 包括對人物／產品嘅固定聯想；Physical appearances 令相似外貌承接原本對某人嘅正面印象，因此模特兒選擇會影響理解。Descriptive terms 亦可能觸發刻板印象。

First impressions 往往持久，因為人一開始就在判斷邊啲線索重要、相關或有預測力。Halo effect 係用單一維度嘅印象擴展去評價其他維度，例如因為喜歡品牌外觀而推斷產品全面優秀。末頁係當時課堂安排同下一章 Memory and Knowledge 預告。

Exam trap：好睇、熟悉或名人代言所帶嚟嘅好感，唔係其他產品表現已被證明。

考試陷阱速覽

  • 有接觸唔等於有注意，更唔等於有理解。
  • JND 睇相對改變，唔係固定金額。
  • 唔好將 subliminal perception 寫成必定改變購買行為。
  • Perceptual defense 針對威脅；blocking 針對資訊轟炸。
  • Halo effect 用單一維度推及其他維度。

優先記熟

  1. Exposure → Attention → Interpretation。
  2. Absolute threshold 同 Differential threshold / JND。
  3. Weber’s Law 同改善／負面改動嘅應用。
  4. 四種選擇性處理及 zipping / zapping。
  5. 注意力有限、adaptation、pre-attentive processing。
  6. Figure-ground、Grouping、Closure。
  7. Schema 同 Halo effect。

Memory and Knowledge

按原講義次序整理 · 頁碼指 PDF 頁序

消費者唔會由零開始理解產品，而係用記憶中已有嘅知識。呢課由記憶點樣入庫、儲存、提取開始，再講知識點樣整理成 schema、script 同類別。最後要掌握：資訊明明學過，點解買嘢嗰刻都未必諗得返，以及品牌可以用咩線索幫人提取。

PDF 第 3–10 頁

1. 記憶流程同三個儲存系統

記憶係知識庫，亦會反過來影響資訊處理。流程係外部輸入 → Encoding（放入記憶）→ Storage（保留）→ Retrieval（需要時搵返）。任何階段缺少進一步處理都可能流失。

系統內容與處理
Sensory memory非常短暫嘅感官分析：Iconic 係視覺、Echoic 係聽覺、Olfactory 係嗅覺。
Short-term / Working memory正在使用或理解嘅資訊，容量有限而短暫；可用 imagery processing 或 discursive processing。
Long-term memory較持久儲存；Episodic / autobiographical 係自身過往經歷；Semantic 係離開具體事件嘅一般知識。

資訊經 attentional gate 進入 working memory，再經 deep processing 進入 long-term memory。Explicit memory 係有意識知道自己記得；Implicit memory 係唔自覺記得，但可以令處理更順暢（processing fluency）。Explicit memory 可表現為 Recognition：再見刺激時認得；或 Recall：未再見刺激都提取得出。

Exam trap：LTM 較持久唔代表永遠提取到或永遠準確；Recognition 有再接觸提示，Recall 冇。

PDF 第 11–17 頁

2. 記得更好：分組、複誦、深度聯繫

Chunking 將細項組成一個有意義單位。品牌本身都可以係一個 chunk，將產品、經驗、形象一併帶出。講義採用一次處理約三至四個 chunks 嘅說法；電話分段或轉成字詞係例子。

方法要點
Maintenance rehearsal主動、有意識重複資訊，例如背乘數表。
Elaborative rehearsal / elaboration將新資訊同已有知識、經驗連結，作較深處理，支持長期記憶。
Recirculation冇主動複誦下，靠簡單重複接觸增強記憶，常見於低投入情境。

健康食品例子：有動機嘅人會研究成分，將佢同健康知識連起，而唔止重複名詞。講義提到 elaboration 差異可能幫助解釋不同年齡組別嘅記憶表現。

圖片補充：HSBC「Different Values」保持主題相同，但轉換背景或物件，減少 advertising wearout。同一剃頭圖像配 style、soldier、survivor；狗可以係 companion、accessory、alarm clock；朱古力可係 energy、indulgence、sin。重點係相同物件可因價值觀同文化產生不同意思，重複主題亦可保留變化。

Exam trap：Recirculation 唔要求主動複誦；Elaboration 唔係單純重複更多次。三至四 chunks 唔等於只可記三至四個字。

PDF 第 18–23 頁

3. 知識內容：schema、image、personality 同 script

Knowledge content 係記憶中已有嘅資訊。一個概念連住嘅聯想集合係 Schema，幫助組織及解讀事物。產品類別、品牌、人、店、國家或自己，都可以有 schema。Image 係其中特別突出嘅聯想子集；Brand personality 係將品牌擬人化嘅一組聯想。

人格維度圖中描述
SincerityDown-to-earth、honest、wholesome、cheerful
ExcitementDaring、spirited、imaginative、up-to-date
CompetenceReliable、intelligent、successful
SophisticationUpper class、charming
RuggednessOutdoorsy、tough

圖例用 Woodland 代表 outdoorsy，Harley-Davidson 代表 rebel，Marlboro 代表 ruggedness，MTV 代表古怪活潑嘅品牌聯想。品牌可透過新產品、媒體、人物或地方改變 schema；強而正面嘅聯想亦有助承受危機。

Script 係特別類型嘅 schema，內容係完成活動嘅動作次序，例如餐廳點餐、入油、買車、用 Nespresso。品牌可以成為日常程序一部分。Oreo 影片頁係呢個主題嘅課堂例子，PDF 本身未提供片內完整內容。

Exam trap：Schema 係聯想網絡，Script 特別指活動次序；Image 唔等於完整 schema。

PDF 第 24–29 頁

4. 知識結構、典型例子同產品推論

相似物件放同類，叫 Taxonomic categories。圖表由廣到窄：Superordinate level 嘅 Beverages → Basic level 嘅 tea、coffee、soft drinks、bottled water、juice → Subordinate level 嘅 diet / nondiet → 品牌／實例，例如 Diet Coke、Diet Pepsi → features / associations。

分類唔只係名詞問題，亦決定新產品同邊啲產品比較。Ritz chips 延伸圖展示餅乾與薯片貨架；Motorola Envoy（1994）係辨認類別嘅討論例子，講義未寫出完整答案。

Prototype 係最有代表性嘅類別成員，同類共享特徵最多、同其他類別共享最少。類別可有典型程度高低（graded structure）；冇明確 prototype 時，pioneer brand 可能擔任相似比較角色。品牌可定位接近典型，或者刻意遠離以作區分。

消費者會根據品牌名、標誌、產品特徵、原產地、包裝設計同顏色作 Inferences。名稱可能誤導或太相似；Swatch 圖例展示品牌符號；Barilla 將意大利同好味 pasta 連起，利用 country-of-origin 線索。

Exam trap：Prototype 係代表性，唔等於每項品質都最高；原產地聯想係推論，唔係實測證據。

5. 提取、啟動同遺忘

當某個概念節點（node）被啟動，能量可沿聯繫傳去其他節點，稱 Spreading activation。強連結較易帶出相關項目；啟動未足以即時提取時，都可能先 prime 個概念，令之後遇到其他提示時更容易想起。

現象辨認方法
Decay少用或時間過去，記憶痕跡／連結減弱。
Interference相似廣告互相干擾，或已有資訊阻礙新資訊儲存。
Primacy effect一串資訊最先出現嘅較易記得。
Recency effect最後出現嘅較易記得。
Retrieval errors記憶可以選擇性、不完整或被扭曲。

Exam trap：冇諗起唔一定等於從未儲存；Retrieval failure 同 Retrieval error 亦唔相同。

6. 幫消費者喺需要時諗得返

提取能力取決於刺激本身、連結、處理方式同消費者狀態。

因素解釋
Salience突出嘅刺激吸引注意，促進 elaboration。
Prototypicality / pioneer brands同更多概念有緊密聯繫，較容易被提取及納入評估。
Redundant cues自然配合嘅重疊線索，例如產品示範配旁白，可強化意思；冇新增價值嘅重複亦可能令人忽略。
Medium揀最適合記憶處理嘅媒體。
Retrieval cue內在或外在提示，例如品牌名、包裝、類別名、logo。Energizer 包裝重現廣告兔仔，將購物點同廣告記憶連起。

5. 解釋失敗：味覺、推論同整體配合

MIB → awareness → trial → thinking / inferences → persuasion（image）→ re-purchase

1. 態度、ABC 同三種形成次序

Attitude 係學習而來、對某個對象有相對一致好惡嘅傾向，亦係對人、物、議題或行動嘅整體評價。佢會引導想法（cognitive）、感受（affective）同動作傾向（conative），形成穩定後較難改變。

ABC 成分內容
Affect對產品或品牌嘅情緒／感受。
Behavior / Conation採取某動作嘅傾向、可能性、意願。
Cognition由直接經驗及其他資訊建立嘅知識、信念、感知。
Hierarchy of effects次序基礎
High involvementThink → Feel → DoCognitive information processing
Low involvementThink → Do → FeelBehavioral learning
Zajonc’s / experientialFeel → Do → ThinkHedonic consumption

Consistency principle：人想令想法、感受、行為一致，出現不一致就可能改其中一項。Cognitive dissonance 係態度同動作不一致時嘅張力，令人採取行動減少不協調。Balance theory 睇三角關係：自己、態度對象、另一個人／物，以及點樣改評價維持平衡。

完整 TORA：行為結果信念及結果評價 → attitude toward behavior；重要他人認為應唔應做嘅信念，加上願意服從程度 → subjective norm；態度與主觀規範共同影響 intention，再連到 behavior。改變策略包括改 beliefs、改 evaluation、加入新 belief、處理 normative beliefs，同想像經驗。Congruity theory 指將較負面對象同受喜愛人物連起，可能提升前者評價。

認知態度受來源同訊息影響。Source credibility 包括 trustworthiness、expertise、status；公司聲譽亦重要。Sleeper effect 指來源可能比訊息更快被忘記。圖例列出 Cialdini 嘅 liking、authority、reciprocity。訊息可用 strong arguments、one-sided（只正面）、two-sided（正負都有）、comparative（直接同對手比）。比較廣告可幫新品牌貼近主流參照點、建立形象，但亦可能減可信度同增加 SD。

高 affective involvement 會帶來較整體嘅圖像／情緒處理；emotional appeal 用情緒影響態度。來源嘅吸引力、親切、熟悉、相似性都有影響；Match-up hypothesis 要來源同產品配合。Fear appeals 強調負面後果；Terror management theory (TMT) 睇人點樣透過捍衛世界觀、價值同信念回應死亡威脅。

5. 廣告態度模型同低投入認知

Attitude-Toward-the-Ad Model：接觸廣告後產生 judgments（cognitions）同 feelings（affects）；兩者都可影響 brand beliefs 同 attitude toward ad，再影響 attitude toward brand。圖亦畫出接觸廣告直接連到 brand beliefs。唔好簡化成單一「鍾意廣告就一定買」。廣告態度有 utilitarian / functional（資訊價值）同 hedonic（感受價值）兩個面向。

低 effort 下可能無意識處理。Thin-slice judgments 係極短觀察後作評價；Body feedback 例如點頭／搖頭可能影響評價。Simple inferences 靠 peripheral cues；Heuristics 係簡單經驗法則；frequency heuristic 靠支持論點數量或重複次數。Truth effect 係因聽過多次就覺得可信。

影響因素包括來源專業形象、同類別／schema 一致嘅資訊、論點數目、簡單訊息、self-referencing、context 同 repetition。重複可以增加 incidental learning、recall 同 truth effect，但圖中特別提醒 wearout。

Self-referencing 可用直接指示、「you」、反問句或常見生活情境圖像；Mystery ads 到尾先揭露品牌。其他做法有 avatar（代表用家／人物嘅圖像）及 scratch & sniff（刮聞感官互動）。PDF 第 47 頁開始印刷頁碼比 PDF 頁序大一，本筆記一律用 PDF 頁序。

Exam trap：本節範圍外。Argument quantity、來源形象同重複唔等於論據品質高。

6. 低投入感受、制約同說服策略總結

Mere-exposure effect / Familiarity principle 指因熟悉而較偏好，可用 repetition、POP displays、me-too products。Classical conditioning 係反覆配對刺激，令原本中性刺激都能引發反應：UCS 自然引發 UCR；CS 同 UCS 多次配對後，CS 引發 CR。Evaluative conditioning 特別指中性品牌同帶情緒刺激配對，形成情感反應。圖例係食物／鐘聲與唾液，以及悅耳音樂／景象同 soft drink；雪糕車及 jingle 頁展示日常聯想。

Mood 會將對其他刺激嘅評價推向同心情一致嘅方向。感受態度受來源外貌、likability、celebrity，以及畫面、音樂、幽默、性、情緒內容、context 影響。幽默廣告可有較高 recognition，但講義質疑會否同樣提升 recall 或 product attitudes；亦可能快速 wear out 或冒犯部分觀眾。

回到整體模型：刺激 → selection / elimination → interpretation → beliefs → attitudes → choice，過程一直受個人、環境同 memory / prior knowledge 影響。Persuasion 係用文字、聲音、視覺、資訊、感受或推理改變態度或行為。
